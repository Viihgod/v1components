# Contributing

Keep changes scoped to one component or one intentional shared behavior. Include a before/after preview and describe the effect on pointer, keyboard, touch, and reduced motion.

## Maintain a release

1. Verify the approved order on the live Lab. Preserve the v1c-<slug> anchors.
2. For the original eleven cards, save the current Code panel output into snippets. For the additional cards, save the example and portable files served at /lab/source/<slug>.
3. Refresh the screenshot and any motion clip for the changed cards. Keep the catalog JSON, per-card documentation, and [full catalog](CATALOG.md) in the same order as the Lab.
4. Verify that source files and media resolve, then tag the new snapshot. See the [motion guidelines](MOTION.md) for the production interaction baseline.
